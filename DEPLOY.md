# Challenger Series Stats — Deploy Guide

## Workflow: adding new tournament data

1. Drop the new PDF(s) into the `results/` folder
2. Run the parser to regenerate the data:
   ```bash
   npm run parse
   ```
3. Commit everything and push to GitHub:
   ```bash
   git add data/tournaments.json results/
   git commit -m "Add tournament data YYYY-MM-DD"
   git push
   ```
4. Vercel auto-deploys in ~30 seconds.

---

## First-time setup

### Local development
```bash
npm install
npm run parse      # generate data/tournaments.json from PDFs
npm run dev        # http://localhost:3000
```

### Deploy to Vercel
1. Push this folder to a GitHub repository
2. Go to https://vercel.com/new → Import Git Repository
3. Framework: **Next.js** (auto-detected)
4. No environment variables needed
5. Click **Deploy**

> Note: `results/` PDFs do NOT need to be deployed to Vercel.
> Only `data/tournaments.json` (generated by `npm run parse`) is needed.

## Project structure

```
results/          ← PDFs (local only, not deployed)
data/
  tournaments.json  ← generated data (committed to git)
scripts/
  parse_pdfs.py   ← Python parser (requires: pip install pdfplumber)
src/
  app/
    page.tsx        ← Dashboard
    players/        ← Player list + individual profiles
    stats/          ← Advanced stats leaderboards
    h2h/            ← Head-to-head comparison
  lib/
    data.ts         ← Data loading utilities
  components/       ← UI components
```

## Stats explained

| Stat | Description |
|------|-------------|
| **Rey del Deuce** | Win rate in sets that reached 10–10 |
| **Comeback Rate** | Win rate after losing the first set |
| **First Set Impact** | How often winning the 1st set leads to winning the match |
| **Set Dominance** | % of individual sets won |
| **H2H** | Head-to-head record between any two players |
| **Recent Form** | Last 5 matches with result and score |
